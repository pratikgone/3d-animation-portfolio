## ✨ Overview

An immersive, high-performance **3D Spatial Animation Portfolio** featuring a real-time WebGL interactive solar system engine, deep space galaxy particle fields, NASA ambient space acoustics, and production-grade full-stack project showcases.

---

## 🚀 Key Features

* 🪐 **Real-Time 3D Solar System Engine:** All 8 planets, the blazing Sun with plasma flares, orbiting Luna (Moon), dual Saturn rings, and 1,400+ Asteroid belt particles.
* 🛰️ **Interactive Viewport Telemetry:** Fly 3D camera target tracking to any planet with smooth easing transitions.
* ⚡ **Warp Speed Simulation:** Relativistic starfield streaking & accelerated orbital mechanics.
* 🎵 **NASA Ambient Space Sound Synthesizer:** Real ambient cosmic sound FX with interactive mute/unmute audio engine.
* 📩 **Direct SMTP Contact Delivery:** Real-time form transmission delivering directly to `pratikgone1678@gmail.com`.
* 📱 **100% Mobile & Touch Responsive:** Custom mobile HUD drawer, swipeable category strips, and zero-overflow layout.

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/pratikgone/3d-animation-portfolio.git
cd 3d-animation-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
